# Meeting Metadata Template

```markdown
# 会议元信息

## 必填

会议主题：
会议日期：
会议类型：专家访谈 / 用户调研 / 内部会议 / 其他
行业/领域：
参会角色：
音频文件：
是否允许本次外部 API 处理：是 / 否

## 选填

会议目的：
关注问题：
输出目录：（可留空；默认在专家访谈文件夹下新建 `会议主题-会议日期` 文件夹）

## 术语表

每行一条。只有这里明确出现的词，才允许用于术语修正或同音词修正。

示例：
FB=Facebook
飞书=Feishu
```

## 正式运行前确认

在运行完整工作流前，必须由用户确认：

- 音频会上传至火山 TOS 私有桶，并生成短期预签名 URL 提交给豆包 ASR。
- 转写得到的逐字稿会提交给 DeepSeek 生成会议纪要。
- 本次运行允许外部 API 处理字段必须填 `是`。
